# Webapp — Paketstationen Deutschland

Next.js (App Router) + Leaflet, interface in German, Italian and English. The data comes from
`public/municipalities.json` and `public/data/`, generated by `scripts/build_data.py` in the
repository root.

```bash
npm install
npm run dev     # http://localhost:3002
npm run build && npm start
```

Pages: `/` (map, `?gemeinde=<slug>&lang=de|it|en`), `/embed?gemeinde=<slug>`, `/data-export`
(downloads), `/data-export/matrix`, `/data-export/statistics`, `/data-export/coverage`,
`/data-export/updates`, `/api/v1/docs`.

Translations: `lib/messages/{de,it,en}.ts` (German defines the keys); React side in `lib/i18n.tsx`,
server side (API routes) in `lib/translate.ts`.

Optional environment variables: `GITHUB_REPOSITORY` (owner/repo, link to the logs),
`PHOTON_URL` (Photon instance for the address search).
